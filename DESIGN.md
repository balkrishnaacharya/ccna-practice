## 2. Design Rationale

- **Dark canvas + warm paper**: `#181815` base with `#F6F2E9` paper text creates high contrast (≈15:1) while avoiding pure-black eye strain in long study sessions.
- **Gold as sole chromatic accent**: Restricting saturated color to `#BD8D39` keeps the interface focused; secondary roles (sage/heart/peach) carry semantic state only.
- **Serif headings + sans body**: Editorial serif for page titles signals authority (blueprint documentation); Inter sans for UI keeps dense data legible at small sizes.
- **Pill morphology**: `rounded-full` applied to buttons, nav pills, stat badges, and chips creates a unified, friendly visual language across touch targets.
- **Compositor-only motion**: Blob animations use `transform` + `will-change` and pause when tabbed away; GSAP tweens avoid layout properties. This preserves 60fps on mobile (Android target).
- **Safe-area awareness**: `--safe-top` / `--safe-bottom` CSS vars plus Tailwind `pb-safe` keep content clear of Android notches and home indicators.

## 4. Extension Guidance

- Add new semantic colors under `theme.extend.colors` in `tailwind.config.js`, following the existing `{DEFAULT, hover, light, glow}` shape.
- Keep all color values as CSS-color-compatible strings (hex or rgba) so they can be promoted to CSS custom properties later.
- Do not introduce arbitrary hex values inline; route through the token map to preserve consistency.
- New motion must honor `prefers-reduced-motion` and use transform-only properties where possible.
